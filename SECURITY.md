# Security Policy

This repository mirrors two scripts from a student course project (DDMO
SoSe 2026, day-ahead electricity load forecasting challenge). It is not
a production system and does not process secrets, credentials, or
personal data — it forecasts publicly-available aggregated electricity
load figures.

## Reporting a Vulnerability

If you find a security issue in this code or its dependencies, please
open a GitHub issue on this repository, or contact the maintainer
directly via the GitHub profile linked on this repo. There is no bug
bounty; this is a student project.

For vulnerabilities in the underlying `spotforecast2` /
`spotforecast2-safe` libraries themselves (not this repo's own code),
please report to their maintainer instead:
https://github.com/sequential-parameter-optimization/spotforecast2-safe
